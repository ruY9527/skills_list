# 小红书图文草稿自动化流程（Windows Win32）

> **目标页**：`https://creator.xiaohongshu.com/publish/publish?target=image`
> **终点**：点击「暂存离开」保存草稿，**永不点击「发布」**。

---

## 1. 执行顺序（7 步，每步截图核验）

1. `SetProcessDpiAwareness(2)` → 按关键字 `"创作"` / `"creator"` 查找已登录的 Chrome 窗口 → 强前台。
2. 导航到 `https://creator.xiaohongshu.com/publish/publish?target=image`（`Ctrl+L` → 粘贴 URL → `Enter` → 等待 7s）。
   - 注意：`Ctrl+T` 在部分情况下会打开后台标签，需要显式切到目标标签；若书签栏遮挡顶部，先按 `Esc`。
3. 上传图片：点击空态「上传图片」按钮 → 捕获 `#32770` 原生文件对话框 → `WM_SETTEXT` 写入双引号空格分隔的多文件路径并 `WM_GETTEXT` 读回校验 → `BM_CLICK` 点击「打开」按钮 → 等待 15s。
4. 填标题：点击标题框文字基线（**必须在缩略图下方**）→ 剪贴板粘贴 → 截图核验。
5. 填正文：点击正文框 → 剪贴板粘贴 → 按 `Ctrl+Home` 回到首段再截图核验（避免自动滚动导致误判丢前文）。
6. 追加标签：点击正文区 → `Ctrl+End` 到文末 → `Enter` → 逐个粘贴 `#标签`，每次等待 `1.4s` 后按 `Enter` 选中下拉第一项。
7. 保存草稿：点击「暂存离开」→ 等待 4s → 截图核验。

---

## 2. 参考坐标（2560×1440，DPI 96，最大化窗口）

> **铁律**：窗口是否最大化、页面居中/左对齐布局、书签栏状态都会导致坐标偏移，执行前必须先截图裁剪标定！

| 元素 | 左对齐参考坐标 | 居中布局参考坐标 | 说明 |
| :--- | ---: | ---: | :--- |
| 上传图文标签 | `(448, 157)` | — | 书签栏展开会遮挡，先按 `Esc` |
| 空态「上传图片」按钮 | `(790, 500)` | `(1295, 745)` | 仅在无图时出现 |
| **标题输入框** | **`(900, 405)`** | `y≈400` | **核心坑**：`y≈145–390` 是图片缩略图区！ |
| **正文输入框** | **`(900, 448)`** | `y≈446` | 严格在标题之后填写 |
| 标签锚点（正文内） | `(900, 500)` | `y≈500` | 点击后接 `Ctrl+End` |
| **暂存离开** | **`(1066, 1342)`** | `(1039, 1337)` | 唯一允许的保存按钮 |
| 发布（**禁用**） | `(868, 1342)` | `(1197, 1337)` | **绝不点击** |

### 最大陷阱：`y=274` 缩略图区
上传图片后，缩略图栏会占据 `y≈145–390`。若将标题框错定在 `y=274`，每次点击都会重新弹出文件选择框而非聚焦标题。务必确认标题占位文字「填写标题会有更多赞哦」的基线在缩略图**下方**（`y≈400–405`）。

---

## 3. 验收标准

- [ ] 缩略图栏出现全部图片，右上显示 `n/18`。
- [ ] 标题框有完整文字 + 右上字数计数（如 `18/20`）+ 右侧手机预览同步显示标题。
- [ ] 按 `Ctrl+Home` 后可见正文第一段。
- [ ] 文末出现全部 `#标签` 且总字数未超 `1000`。
- [ ] 点击「暂存离开」后，顶部出现绿色 **「保存成功」** 提示，草稿箱计数 `+1`，列表中可见标题与封面。
- [ ] **「发布」从未被点击**。

---

## 4. 失败 → 修法速查

| 症状 | 原因 | 修法 |
| :--- | :--- | :--- |
| 一直弹文件选择框 | 标题坐标落在缩略图区（`y≈274`） | 重新截图标定，标题在缩略图下方（`y≈405`） |
| 标题文字粘进了正文 | 正文先获焦，或点偏了 | 严格按「标题 → 正文」顺序，每步单独截图验证 |
| 粘贴无反应 / 焦点丢失 | 点击 `contenteditable` 后又调了 `SetWindowPos` | 只在点击编辑器**之前**强前台，不要在点击后重置窗口 z-order |
| 正文只看到后半段 | 粘贴后编辑区自动滚到底部 | 按 `Ctrl+Home` 回到顶部再截图 |
| 坐标整体偏移 | 漏掉 DPI 感知 | 首行必须执行 `SetProcessDpiAwareness(2)` |
| `SendMessageW` 报 `TypeError` | 第 4 参数 `argtypes` 写成了 `LPARAM` | 改为 `ctypes.c_void_p` |
| 对话框点「打开」无效 | 发送了 `WM_COMMAND IDOK` | 必须枚举 `Button` 子窗口对「打开」发 `BM_CLICK` |
| 同窗口其他标签抢焦点 | 多标签共享 Chrome 窗口 | 使用 `chrome --app=URL` 开独立窗口 |
