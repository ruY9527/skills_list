# 抖音图文草稿自动化流程（Windows Win32）

> **目标页**：`https://creator.douyin.com/creator-micro/content/post/image`
> **终点**：滚到底部后点击「暂存离开」保存草稿，**永不点击「发布」**。

---

## 1. 与小红书的 6 处核心差异

| 维度 | 小红书 | 抖音 |
| :--- | :--- | :--- |
| **发布页 URL** | `/publish/publish?target=image` | `/creator-micro/content/post/image`（`/content/upload` 是视频页！） |
| **标题框 `y`** | `y≈405` | **`y≈320`**（`y≈210` 是「快速填写」按钮！） |
| **上传入口** | 空态大按钮 `(790, 500)` | 右侧上传区 `(1758, 480)`，上传耗时略长（等 `16s`） |
| **保存按钮** | 直接可见 `(1066, 1342)` | 在首屏下方，**必须先点空白 + 按两次 `End` 滚到底** |
| **保存成功标志** | 顶部绿色「保存成功」toast | **无绿色 toast**；跳回上传页并出现「你还有上次未发布的图文，是否继续编辑？」 |
| **`Ctrl+A` 行为** | 选中当前输入框 | **会全选整个网页！严禁使用 `Ctrl+A`** |

---

## 2. 执行顺序（8 步，每步截图核验）

1. `SetProcessDpiAwareness(2)` → 按关键字 `"抖音"` 查找 Chrome 窗口 → 强前台。
   - 若弹出浏览器位置权限询问框，按 `Esc` 关闭。
2. 导航到 `https://creator.douyin.com/creator-micro/content/post/image`（等待 8s）。
   - **注意**：点页面顶部「发布图文」标签往往不会跳转，必须直接地址栏导航到 `/content/post/image`。
3. 上传图片：点击右侧上传区 → `#32770` 文件对话框 `WM_SETTEXT` 写入多文件路径并读回校验 → `BM_CLICK`「打开」→ 等待 `16s` → 确认「已添加 N 张图片」。
4. 填标题：点击「添加作品标题」文字行（`y≈320`）→ 剪贴板粘贴 → 核验计数从 `0/20` 变为 `n/20`。
5. 填描述：点击「添加作品描述」内部 → 剪贴板粘贴 → 核验计数从 `0/1000` 变为 `n/1000`。
6. 追加话题：点击描述区 → `Ctrl+End` → `Enter` → 逐个粘贴 `#话题`，每次等待 `1.5s` 后按 `Enter` 选中下拉第一项。
7. 滚动到底部：点击页面左侧空白处 `(700, 1200)` 获取滚动焦点 → 按 `End`（等 `1.0s`）→ 再按 `End`（等 `1.5s`）→ 截图确认「暂存离开」已露出。
8. 点击「暂存离开」→ 等待 `6s` → 截图核验是否跳回上传页。

## 3. 参考坐标（2560×1440，DPI 96，最大化窗口）

> 执行前务必先截图并裁剪放大标定，抖音页面元素密集，可用裁剪高度占比反推原图 `y`。

| 元素 | 参考坐标 | 居中布局参考 | 说明 |
| :--- | ---: | ---: | :--- |
| 右侧上传区（「点击上传」） | `(1758, 480)` | `(1732, 471)` | |
| **标题框（「添加作品标题」）** | **`(1100, 320)`** | `(1019, 316)` | **绝不是 `y=210`** |
| **描述框（「添加作品描述」）** | **`(1180, 400)`** | `(1019, 353)` | |
| **暂存离开（滚到底后）** | **`(1101, 1300)`** | `(1076, 1287)` | 唯一允许的保存按钮 |
| 发布（**禁用**） | `(954, 1300)` | `(957, 1287)` | **绝不点击** |

### 抖音特有干扰元素（严禁误点）

| 干扰元素 | 大致位置 | 后果与处理 |
| :--- | :--- | :--- |
| 「快速填写」按钮 | `(1517, 172)` / `y≈210` 附近 | 点中无报错但标题填不进去 |
| 顶部「AI 工坊」横幅 | 顶部导航区 | 误点会直接跳离图文编辑页 |
| 剪映广告卡片 | 页面中部 | 误点跳出 |
| 「清空并重新上传」 | 右侧 `(1738, 848)` | 误点会清空已上传图片 |
| 位置权限弹窗 | 左上角 | 按 `Esc` 关闭 |

## 4. 验收标准

- [ ] 显示「已添加 N 张图片」，缩略图全部可见。
- [ ] 标题框有文字 + 计数 `n/20`。
- [ ] 描述框有完整正文 + 文末话题 + 计数 `n/1000`。
- [ ] 点击「暂存离开」后，页面**跳回上传页**，顶部出现 **「你还有上次未发布的图文，是否继续编辑？」**（`[继续编辑] [放弃]`）。
- [ ] **「发布」从未被点击**。

---

## 5. 失败 → 修法速查

| 症状 | 原因 | 修法 |
| :--- | :--- | :--- |
| 标题怎么都填不进且不报错 | 点到了 `y≈210` 的「快速填写」 | 改标定到 `y≈316–320` 的「添加作品标题」 |
| 进了视频上传页 | 访问了 `/content/upload` | 改为 `/creator-micro/content/post/image` |
| 找不到「暂存离开」 | 未滚动到底部 | 点空白 `(700, 1200)` 后按两次 `End` |
| 保存后没看到绿色提示 | 抖音本身没有 toast | 看是否跳回上传页并出现「未发布的图文」横幅 |
| 描述内容被误清空 | 用了 `Ctrl+A` | 抖音禁止使用 `Ctrl+A`（会全选整页） |
| 位置权限弹窗挡住操作 | Chrome 权限询问 | 先按 `Esc` 关闭 |
